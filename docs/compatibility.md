# 适配与验证

## 功能适配

| 环境 | 通用管理 | 联想模板阻挡 | 自定义分支补丁 |
| --- | --- | --- | --- |
| Windows x64，无 Legion Zone | 可用，仍需检测系统能力 | 不适用 | 不适用 |
| Legion Zone 2.0.28.8182，已知开关/模板完整 | 可用 | 规则匹配时开放 | 还需匹配完整 DLL SHA256 |
| 其他 Legion Zone、Vantage、Commercial Vantage | 可用 | 未适配 | 未适配 |
| Modern Standby 或状态未知 | 枚举/导入可用；激活仅允许已确认的平衡类型 | 受当前规则限制 | 受当前规则限制 |
| Windows ARM64 / x86 / Windows 7 / 8 | 首版不支持 | 不支持 | 不支持 |

目标系统为 Windows 10 22H2 / Windows 11 x64。目标不等于已经实测，且不代表这些系统的微软生命周期状态。

## 本机记录

- Windows 11 build 26200、Legion Y7000P IRH8：普通权限 GUI 启动、设备识别、计划枚举、四个页面、固定资源下载与 SHA256 检查已实测。
- 界面内容缩放 100% / 125% / 150% 已检查；多显示器间 DPI 切换尚未实测。
- 2026-09-06 的旧版补丁已完成真实写入、托盘加载和初始化后 12 秒观察；2026-09-08 新 GUI 只读确认补丁状态仍为已应用。
- 本次 GUI 开发没有重新给日常系统应用/撤销 DLL 补丁，没有切换或删除日常电源计划。
- 游戏启动、全部模式切换、系统重启、不同机型、Windows 10、第三方计划性能与续航尚未验证。

## 自动验证

- PowerShell 5.1 / 7：基础脚本、分支补丁及通用引擎隔离测试；模拟系统接口，不修改运行测试者的计划。
- .NET 桌面检查：资源固定版本、损坏下载、离线缓存、参数白名单、取消提权及操作文件锁。
- GitHub Desktop 工作流在 Microsoft 托管的临时 Windows VM 运行 Invoke-VmValidation.ps1：逐个核验 7 个固定文件并尝试导入，成功后读取参数并删除，拒绝时确认无残留；第三方计划不激活。另用导出的 Windows 平衡副本验证导入、激活、删除、恢复往返。
- 原生验证要求显式 -AllowVirtualMachineChanges、虚拟机机型和管理员权限，不应在日常主机运行。
- 原生测试结果以对应提交的 Actions 状态和 vm-validation 工件为准；Windows Server 运行器的结果不能替代 Windows 10/11 笔记本实测。
- [修复后的完整工作流](https://github.com/fananly233/legion-zone-power-plan-tools/actions/runs/34300924104)已通过：PowerShell 5.1/7 隔离测试、桌面检查、原生恢复往返、管理员工作进程的命名管道/内嵌桥接/原生导出集成测试及便携打包。真实 UAC 交互和完整 GUI 修改流程尚未在日常主机测试。

没有兼容性和稳定性证据的环境不标成“已验证”，也不承诺多数联想机型能完整阻止所有自动创建来源。

## 固定资源原生审计

[首次完整资源审计](https://github.com/fananly233/legion-zone-power-plan-tools/actions/runs/34300677437)使用 Windows Server 2025 Datacenter 26100 临时 VM。所有下载 SHA256 匹配；5 个文件完成导入、交流电/电池参数读取和删除，2 个被原生接口拒绝；全部确认无残留，原活动计划不变。平衡副本的完整操作/恢复往返通过。该次运行随后发现工作进程模块加载问题，不能当作整个版本通过的证据。

| 资源 | 原生导入 | AC / DC 类型索引 | 范围 |
| --- | --- | --- | --- |
| ACMEPCAMD | 成功 | 1 / 1 | 非平衡类型；读取全部可枚举参数 |
| AMD 电源计划 | 成功 | 1 / 1 | 非平衡类型；读取全部可枚举参数 |
| Intel 大核心电源计划 | 成功 | 1 / 1 | 非平衡类型；读取全部可枚举参数 |
| PowerX v2 | 拒绝 | 未取得 | 系统报告设置值格式错误或超出范围 |
| ggOS Desktop Gaming | 拒绝 | 未取得 | 已确认下载文件存在且哈希匹配，但原生导入报告找不到文件；原因尚未确定 |
| 卓越性能（NexBox 文件） | 成功 | 1 / 2 | AC 非平衡 / DC 平衡；读取全部可枚举参数 |
| optimizerDuck | 成功 | 1 / 2 | AC 非平衡 / DC 平衡；读取全部可枚举参数 |

索引 1 对应高性能 personality，2 对应平衡 personality，不代表各个参数采用 Windows 默认值。两种供电状态均为平衡类型才满足本工具的现代待机激活规则。上述结果不替代 Windows 10/11 客户端兼容性和实际电池测试。两个被拒绝资源尚未完成参数检查，仍收录并展示限制，不标为验证通过。
